# Porting Guide

## Philosophie

Le but n'est pas de réécrire totalement un jeu Pokitto.

Le but est de :

- conserver le code métier ;
- remplacer les APIs matérielles ;
- fournir un environnement AKA natif.

## Processus

1. Analyse du projet
2. Détection des APIs
3. Conversion des assets
4. Génération du manifest
5. Compilation
6. Validation

## Respect des auteurs

Chaque portage doit conserver :

- auteur original
- licence originale
- dépôt source
- notes de portage

## Vérifications obligatoires

- Menu système
- Captures écran
- Retour loader
- Sauvegardes SD
- Crédits
- Licence
